# H1 — Real data on the laptop + environment check

| Kind | Gate | Previous | Next |
|---|---|---|---|
| human only | H1 | S00.1 | S00.2 |

## You do
1. Create a data folder outside or inside the repo (inside: `data/real/`, which is git-ignored). Put `WM290V_RedrawStart.stp` (uncompressed is fine) and the provided `key_part.step` (green faces) there; optionally `key_faces.txt` (one face ID per line) and an extra public assembly (bench vice).
2. Set the environment variable `FITFINDER_DATA` to that folder (macOS/Linux: `export FITFINDER_DATA=$PWD/data/real`; Windows PowerShell: `$env:FITFINDER_DATA="$PWD\data\real"`). Add it to your shell profile.
3. Write checksums into `data/SHA256SUMS` (HUMAN_GIT.md §8) — this file IS committed.
4. Run `python tools/verify_h.py H1` — it must print PASS (it reads the key part and WM290V with OCCT and reports counts and timings).

## Automated check
```bash
python tools/verify_h.py H1     # must print PASS; writes reports/H1/report.json
```
